## Architecture

The library models "noisy values" — observations paired with a symbolic posterior over their true value — using SymPy for symbolic math and NumPy/SciPy for sampling.

### Core abstractions (`src/core.py`)

**`Node`** is the fundamental unit. Every noisy value is backed by a DAG of `Node` objects, each holding:
- `role`: `"latent"` (unknown true parameter), `"noise"` (random variable with a known distribution), or `"derived"` (algebraic combination)
- `symbol`: a unique SymPy `Symbol` auto-generated by `util.fresh_name()`
- `source`: a `NoiseSource` instance (for noise nodes); can reference other node symbols as parameters for hierarchical/dependent noise
- `constraints`: equations that pin latent symbols (e.g., `obs = theta + eps`)
- `deps`: parent nodes, forming the DAG

**`NoisyValue`** wraps a `(obs, root_node)` pair. Subclasses enforce the observed type:
- `NoisyFloat` — real-valued observations; supports arithmetic, exp/log/sqrt, rounding
- `NoisyInt` — integer observations; supports constructor helpers like `NoisyInt.binomial(...)`
- `NoisyBool` — boolean observations; supports `&`, `|`, `~`
- `NoisyNumber` — shared numeric base (comparison operators that return `NoisyBool`, `guarded()`)

Arithmetic operators on `NoisyValue` subclasses call `bin_op` / `unary_op`, which compose both the observed scalar and the symbolic expression in tandem.

**`NoisyValueSampler`** (returned by `noisy_value_sampler()`) does the heavy lifting:
1. Collects all latent symbols and constraints across a joint set of values
2. Solves latent symbols symbolically via `sympy.solve` (static substitutions, computed once)
3. Separates noise nodes into *independent* (no `deps`) and *dependent* (hierarchical)
4. On each `.sample(n)` call, bulk-samples all independent noise via NumPy, then resolves dependent nodes in topological order using `source.instantiate(resolved).sample(rng)`, then evaluates expressions via `sp.lambdify`
5. Returns a `SampleBatch` wrapping a 1-D NumPy array

### Supporting modules

- **`src/noise.py`** — `NoiseSource` base class and two concrete subclasses: `NormalNoiseSource`, `BinomialNoiseSource`. Each implements `free_symbols` (SymPy symbols its parameters depend on), `instantiate(resolved)` (substitutes resolved values into parameters), `sample(rng, size)` (NumPy sampling), and `sympy_rv()` (returns a SymPy RV for visualization). Use the public constructors `gaussian(loc, scale)` and `binomial(n, p)` — parameters can be plain numbers, SymPy expressions, or `NoisyFloat`/`NoisyInt` values.
- **`src/analysis.py`** — `NoisyContingencyTable` wraps a 2-D array of `NoisyNumber`s and provides `chi_squared()`, `odds_ratio()`, and `with_stratified_sampling_uncertainty()` (the last one adds binomial sampling uncertainty row-by-row, which is the key differential-privacy use case). Also exposes `noisy_min` / `noisy_max`.
- **`src/array.py`** — `float_array_sampler` / `sample_float_array` for sampling tensor-shaped collections of noisy values jointly.
- **`src/visual.py`** — `plot_posterior()` renders posterior densities deterministically via tensor-product Gauss-Legendre quadrature in quantile space (no Monte Carlo), then weighted KDE. Uses `source.sympy_rv()` to get quantile functions for each noise source. Requires `matplotlib` (dev dependency).
- **`src/util.py`** — `fresh_name()` / `reset_name_provider()` for globally unique SymPy symbol names. Tests call `reset_name_provider()` via `conftest.py` to avoid symbol collisions.
- **`src/census.py`** — `get_pl94()` / `pl94_queries()`: tidycensus-style access to the 2020 Census PL94-171 Noisy Measurement File parquet release in `data/2020-pl94-nmf-parquets` (Hive-partitioned by state; scanned lazily via polars with partition pruning). Returns tidy pandas DataFrames whose `value` column is a `NoisyIntArray` of discrete-Gaussian posteriors. NMF constraint rows are not exposed; they condition the posteriors instead (exact housing-unit totals via closed-form conditioning, structural zeros, hhgq interval bounds via `TruncatedDiscreteGaussianNode`, nonnegativity truncation). Geocodes are DAS spine codes: standard GEOIDs are derived for every level except block groups (spine "optimized block groups" ≠ tabulation block groups); the spine also splits states into non-AIAN/AIAN branches (`aian` column). The codebook orderings (cenrace 63 combos, hhgq 8 levels, etc.) were validated against published 2020 tabulations in `test/test_census.py`.

  `get_dhc()` / `dhc_queries()` / `fetch_dhc()` do the same for the 2020 DHC *person* NMF, whose histogram is `relgq(42) x sex(2) x age(116) x hispanic(2) x cenrace(63)` — the product that carries **sex and age**, which PL94 lacks entirely. Everything below `get_pl94`/`get_dhc` is shared: each product is a spec dict (`_PL94_PERSON`, `_PL94_UNIT`, `_DHC_PERSON`) naming its dataset directory, axes, per-axis label tables, query map, constraint rows, and geography levels. That release is not bundled — `fetch_dhc(geography, state=..., county=...)` mirrors just the partitions asked for from the public Census S3 bucket into `data/2020-dhc-nmf-parquets` (about 1.5 MB per state, 1.8 MB per county). DHC coverage is us/state/county (the spine's lower DHC levels have no tabulation counterpart). The DHC codebook orderings were recovered from the national file itself (every coarse query is a marginal of `detailed_dpq`, so a wrong grouping disagrees far beyond the noise) and are re-checked in `test/test_census.py`.

  DHC constraint handling (`_dhc_person_rules`) covers all three families of constraint row: the relgq age rules (structural zeros — no 14-year-old householders), the per-facility-type GQ bounds, and `pl94_con`, the published PL94 table, which was an *invariant* of the DHC run and so is exact. Since the DHC histogram marginalizes onto the PL94 one, `_pl94_blocks` splits each query's cells into blocks of exactly-known total (merging each axis only as far as PL94 resolves it; sex always merges, since PL94 has no sex). What a block buys depends on how many of its cells are still free: total zero empties all of them, one free cell is a point mass, two are built jointly by `_conditioned_pair` so they stay anti-correlated and always sum to the invariant, and three or more keep the total only as an upper bound — the exact conditional there is a discrete Gaussian on a lattice hyperplane, which does not factor into per-cell distributions the node graph can sample independently. In practice this pins ~40% of the national detailed histogram and ~95% of a small county's, and it makes male + female exact within each hispanic level.

- **`src/wikimedia.py`** — the Wikimedia differentially-private pageview releases (daily counts per country, project, and page since July 2015). `fetch_pageviews(days)` mirrors the public daily TSVs into `data/wikimedia-pageviews` (~6 MB/day historical, ~25–60 MB/day current; nothing bundled or fetched implicitly; `days_between` builds ranges and skips the five never-released days); `get_pageviews(days, country=..., project=..., page=..., ...)` returns a tidy DataFrame whose `value` column is a `NoisyIntArray` of nonnegative flat-prior posteriors. The module's core is a codebook that routes each row to the mechanism that noised it: three eras (geometric scale 300 then 30; discrete Gaussian with σ²=10/(2ρ) by country risk tier since Feb 2023), seven patch days and an *intermittent* US gap (178 of 226 days) backfilled with the geometric mechanism, dated protection-list revisions (2024-02-15, 2024-05-19, 2026-01-26), and Turkey's undocumented blanket exclusion. Every constant was derived or validated empirically from the released files (a country's minimum released count reveals its threshold, hence its mechanism); live tests in `test/test_wikimedia.py` re-check them but skip unless the probe days are mirrored (the fetch call is in that file's integration-section comment). Cell noise symbols are derived from row identity via `LatticeFamily.cell(symbol=...)`, so — unlike `census.py` — repeated reads of one cell are the same random variable. Caveats that matter downstream: counts are deduplicated and clipped (first 10 unique views per device in the current era), the historical eras did not filter automated traffic (sums track the API's all-agents totals), and an absent row means the noisy count fell below the threshold, not zero. `example/wikimedia_pageviews.ipynb` is the walkthrough, and `docs/wikimedia-errata.md` records every observed departure from Wikimedia's own documentation; `CODEBOOK_AS_OF` marks how far the vendored constants are validated, and the loaders warn beyond it.

### Key design constraint

Every `NoisyValue` carries its full probabilistic provenance in the Node DAG. Sampling is always *joint*: shared nodes (same `symbol`) are sampled once per draw and reused, so correlated values stay correlated. This is essential for the differential-privacy contingency table use case where row marginals must be consistent.
